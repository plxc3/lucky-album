## 双形态 Live2D 体验 · 2026-10-19

[原来的角色变身位置](https://plxc3.github.io/lucky-album/?form=girl#/character)和浮动桌宠已直接使用真实动态模型。点击猫咪就在原地变成女孩，再点击女孩变回小猫；去掉独立体验入口卡片及女孩桌宠的白底边框。该体验使用本项目的 Lucky 猫 v005 与女孩 v010 MOC3，由官方 Cubism Web SDK 渲染；轻点角色本身往返变身，长按 600ms 摸摸。两种形态各有 8 组动作，支持悬停招呼、间隔待机回应、手动暂停、隐藏标签页自动暂停及减少动态。主角和浮宠共用同一个 SDK 初始化，各自管理模型与画布；隐藏、离页分别暂停或释放。原图、日记、独立拟人设定及站姿对照继续保留。

这是公开体验版。动作幅度较轻，女孩的微点头、耳尾与手部由同一回应参数协调；闭眼、口型、独立挥手和完整物理仍未完成，源画 alpha 与部分边界仍需改善，不能称为最终成品。新猫眼 v007 实验没有发布。运行库与模型按访问需要加载，主相册不会预先下载 Live2D SDK。

公开目录仅含运行时 MOC3、纹理、动作和 SDK 组件，不含 CMO3、PSD、Editor／codec、私密授权记录。SDK 版本和字节摘要见 `live2d/distribution.json`，使用条件见 [组件许可页](live2d/licenses.html)。打包检查运行 `node scripts/check-live2d.mjs`；页面须在项目子路径下进行真实浏览器验证。

## 本地运行与发布

需要 Node.js 20 或更新版本，无需安装第三方依赖。

```sh
node scripts/check.mjs
node scripts/serve.mjs
```

预览地址：`http://127.0.0.1:4180/lucky-album/`。预览使用项目子路径，便于发现 GitHub Pages 路径问题。

GitHub Pages 沿用本仓库 `main` 分支根目录发布，`.nojekyll` 让文件直接作为静态资源提供。路由使用 URL hash，原日记链接继续有效。推送前运行检查，并验证手机与桌面布局、变换、互动及媒体查看。

## 文件

- `content.js`：56 条记录及素材路径；`MATERIALS.md`：来源、去重与历史说明。
- `app.js`、`album.js` 及 CSS：页面、相册翻页、日记与完整媒体查看。
- `growth.js`：56 条记录的观察主题、收录批次和累计条数派生。
- `character-rig.js`、`pet.js`、`pet.css`：两种形态的图层、动作和互动。
- `assets/`：完整照片、视频、预览、既有角色插画和字体许可。
- `MEDIA_20261016.json`：本轮 69 个媒体文件的字节长度与 SHA-256。
- `QUALITY.md`：本轮验证范围及限制。

变换由真实模型回正与画布内交接完成，移除原先针对整幅插画的 980ms／1040ms 定时器。点击角色本身触发，保留键盘与减少动态支持。抬爪按 SVG 坐标尺度调整，缩到桌宠尺寸仍可见；先去除原部件轮廓，再叠加局部动作，减少重影。角色页与浮宠的正常交互已替换为上述真实 Cubism 运行时，旧插画仅在加载或 WebGL 失败时提供静态参考。字体为 Noto Serif CJK SC 子集，许可保存在 `assets/lucky-album-serif-LICENSE.txt`。

动效节奏参考主人提供的 [Takayu Motion Reference](https://motion-reference.takayustudio.jp/)。另阅读 [live2d-widget](https://github.com/stevenjoezhang/live2d-widget)、[l2d-widget（原 oh-my-live2d）](https://github.com/hacxy/l2d-widget)、[oneko.js](https://github.com/adryd325/oneko.js) 等作者仓库，借鉴动作状态与切换生命周期。本次没有拷入它们的代码或第三方模型，也没有增加动画依赖。Lucky 自有 Live2D 制作源包另存于维护工作区；当前运行包中的猫为官方Editor导出的v005，女孩为社区codec导出的v012并由官方Core/SDK验证；女孩不称为官方Editor导出。制作工程继续保留本地。
